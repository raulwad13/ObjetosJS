# JavaScript Objects — practice exercises

A collection of small JavaScript exercises covering object literals, property access, updates, arrays inside objects and object methods.

## Topics covered
- Creating objects with properties.
- Reading and changing object properties.
- Storing arrays and values in objects.
- Defining and calling methods.
- Working with values such as dates.

## Technologies
- JavaScript (vanilla)
- HTML5

## Run locally
Open `index.html` in a browser. The exercises run from `objetos.js` and write their results to the browser console.

To view the output, open the browser developer tools and select **Console**.

## Files
- `index.html` — loads the exercise script.
- `objetos.js` — object practice examples.

This repository is an educational exercise rather than a production application.
